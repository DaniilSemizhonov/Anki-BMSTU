# Anki BMSTU

Личный веб-клиент Anki: повторение карточек в браузере, мобильный интерфейс
и подготовленная интеграция с Telegram Mini Apps. Данные и расписание хранит
официальная библиотека Anki.

## Запуск на сервере

Стек разделён на `backend` и `web`. Внешний HTTPS настраивается в вашем Nginx
Proxy Manager, коллекция хранится в постоянном Docker-томе.

```sh
cp .env.example .env
# Задайте свой HTTPS-домен и пароль в .env.
docker compose up -d --build
```

Для общей Docker-сети с Nginx Proxy Manager предусмотрен `compose.npm.yaml`.
Полные команды и параметры: [DEPLOYMENT.md](DEPLOYMENT.md).

## Локальный запуск

```sh
sh web/run.sh
```

Откройте <http://127.0.0.1:8765>. Возможности, тесты и ограничения описаны
в [web/README.md](web/README.md).

## Проверки

Проверки запускаются вручную: `just check-web` проверяет веб-клиент и API,
`docker compose build` собирает оба контейнера. Команда `just smoke-compose`
предназначена только для временного пустого Docker-стека с тестовыми данными.
GitHub Actions и другие автоматические процессы в репозиторий не включены.
